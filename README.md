---

## ⚡ Highlights & Principles

- **Zero AI Slop**: 0% generic Tailwind indigo (`#6366f1`), 0% hero gradient mush, 0% emoji icons in headers, and 0% filler metrics.
- **Craft & Restraint**: Built on an obsidian canvas (`#090a0f`) with surgical signal cyan and emerald telemetry indicators, tight SF Pro display letter-spacing (`-0.035em`), and micro-interactions inspired by Linear and Stripe.
- **Zero External Runtime Dependencies**: 100% self-contained vanilla HTML5, CSS3, and JavaScript. Zero external CDNs. Instant load time with 100/100 Lighthouse performance.
- **Interactive Systems Console**:
  - **Raft Consensus Cluster**: 5-node topology visualizer with real-time heartbeat stepping, network partition injection (isolating minority nodes while maintaining majority quorum), and leader election triggers.
  - **LMAX Disruptor Order Book**: Real-time Price-Time Priority LOB depth with lock-free sequence ring-buffer tracking.
  - **Agentic MCP Protocol Inspector**: Structured JSON-RPC 2.0 tool execution payloads for distributed invariant audits.
- **OpenDesign Ready**: Full semantic structure with `data-od-id` tags across components for design-system auditing.

## 🚀 Running Locally

Because this project is built entirely on native web standards with zero build steps, you can run it immediately:

```bash
# Option 1: Open directly in your browser
open index.html   # On macOS
xdg-open index.html # On Linux

# Option 2: Run a local static server
python3 -m http.server 8000
# or
npx serve .
```
